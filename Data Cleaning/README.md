Data Cleaning

Dataset

Google Trends Dataset (trends.csv)

Cleaning Steps Performed

1. Imported the dataset into Jupyter Notebook using Pandas.
2. Checked for missing values and verified that no missing values were present.
3. Identified and removed duplicate records.
4. Standardized column names by converting them to lowercase.
5. Removed leading and trailing spaces from text fields.
6. Verified and assigned appropriate data types to all columns.
7. Checked for formatting inconsistencies and corrected them.
8. Verified the final cleaned dataset.

Results

* Original Records: 26,955
* Duplicate Records Removed: 10
* Final Records: 26,945
* Missing Values: 0

Files

* trends.csv (Original Dataset)
* trends_cleaned.csv (Cleaned Dataset)
